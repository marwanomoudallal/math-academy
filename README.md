# BrainQuest Academy

A responsive, offline-first educational adventure for children, built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a modern browser. No server, build step, account, or internet connection is required. Progress is saved automatically in the browser's LocalStorage.

## Included

- Connected home dashboard and interactive world map
- Math Battle with categories, combos, power attacks, enemies, and bosses
- Fraction Kingdom with adaptive questions, resources, and visual upgrades
- Typing Defense with moving enemies, waves, bosses, WPM, and accuracy
- Memory Temple with card, pattern, number, word, and picture modes
- Shared levels 1–100, XP, coins, gems, trophies, daily quests, and achievements
- Cosmetic shop, avatars, pets, profile, and offline computer leaderboard
- Difficulty, sound, music, animation, and confirmed progress-reset settings
- Responsive layouts for desktop, tablet, and large phones

The project intentionally uses CSS/emoji artwork and generated sound cues so there are no missing external assets.
